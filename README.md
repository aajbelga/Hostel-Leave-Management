# 🏠 Hostel Leave Management System

A full-stack web application designed to streamline and digitize the hostel leave management process. The platform enables students to submit leave requests online, while wardens and administrators can efficiently review, approve, and monitor applications through a centralized dashboard.

The system enhances hostel security and operational efficiency by incorporating QR-based outpass verification, real-time leave tracking, and parent notification capabilities.

## 🚀 Key Features

### 👨‍🎓 Student Portal

* Secure student registration and authentication
* Online hostel leave application submission
* Real-time leave status tracking
* Complete leave history management
* QR-code based digital outpass generation

### 👨‍💼 Admin / Warden Portal

* Centralized dashboard for leave management
* Approve or reject leave requests instantly
* Monitor student leave records and activity
* QR-code verification for hostel entry and exit
* Student management and tracking system

### 👨‍👩‍👧 Parent Notification System

* Automated leave approval notifications
* Real-time leave status updates
* Email and SMS integration (Planned Feature)

### 🎨 User Experience

* Modern and responsive interface
* Mobile-friendly design
* Multi-page navigation architecture
* Intuitive and user-friendly workflow
